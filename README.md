# VOID//LAB — 3D Experimental Web

A responsive, cyberpunk-inspired interactive landing page based on the visual language of the supplied Instagram references.

## Files
- index.html — page structure
- style.css — responsive styling, glow, glass, glitch and card animations
- script.js — Three.js WebGL scene + controls

## Run
Open `index.html` in a modern browser with internet access (the page loads Three.js and Google Fonts from CDNs).

## Publish for free
Upload the three files to GitHub Pages, Netlify, Vercel, or Cloudflare Pages.

## Customize
Search `VOID//LAB` in `index.html` to replace the brand.
Change the email address in the final CTA.
